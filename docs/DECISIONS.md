# Decisions for milestone 1

1. **Python CLI before a web stack.** It provides a complete input-to-result path Osie can trace using familiar language skills. An API can wrap this core after review. A UI, auth and database now would hide the NLP decisions behind unfamiliar infrastructure.
2. **Dictionary sounds before spelling suffixes.** `through/blue` and `cough/though` illustrate why letters alone fail. Consider every pronunciation; take the last primary/secondary stressed vowel (last vowel if no stress), remove stress digits and compare complete tails. This is an exact-rhyme candidate heuristic, not learned performance assessment. Slant and multisyllable rhyme modeling remain future experiments.
3. **TF-IDF before embeddings.** Count terms, weight terms rare in the indexed corpus, normalize vectors, then take their dot product. For term t in N documents, `idf(t) = log((1+N)/(1+df(t)))+1`. Raw count times idf is L2-normalized. Dividing each count by document length first would cancel during L2 normalization. IDF is fit on indexed bars only, never the query. Query-only terms are ignored; ties sort by ID. Expose matched words so the result can be challenged.
4. **Keep original text and preserve uncertainty.** Normalization affects lookup only. Unknown pronunciations have a separate status. Dictionary entries are not guarantees for any dialect or performer; multiple possible pronunciations can also produce false-positive candidates.
5. **Source labels travel with search output.** Corpus metadata is mandatory. The loader checks structure, unique IDs and declared provenance; it cannot independently verify permission or truthful labels. Human source review remains necessary. Local private contributions belong in ignored `data/private/` until publication permission is explicit.
6. **No real-data metrics from fixtures.** Fixtures are AI-authored test inputs, not gold annotations or model validation. The report deliberately leaves real-data quality metrics null. Future splits must hold out battles, remove duplicate/near-duplicate text, and separately test performer generalization where enough disjoint performers exist. Keep development annotations separate from the frozen test set.
7. **No LLM/API dependency.** Both baselines run offline after install. No hidden paid calls, generated opponent, or claim that a model learned battle rap. The ML progression starts with a measured baseline; neural complexity must earn its place in a held-out comparison.
